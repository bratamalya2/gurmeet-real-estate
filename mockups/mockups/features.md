# Features List

## 1. Front-End Pages
* **Home Page:** Hero section, search/filter bar, featured properties carousel, brief agent introduction.
* **About Us / Agent Profile:** Detailed biography, professional experience, service areas, and mission statement.
* **Services Pages:** Information on Buying Services and Selling Services.
* **Property Listings (Homes for Sale & Recently Sold):** Grid/List view of properties with pagination and filtering.
* **Contact Us Page:** General contact information, operating hours, and location map.

## 2. Lead Capture Forms
* **Property Inquiry Form:** Embedded on individual property detail pages (Name, Email, Phone, Message).
* **Schedule-a-Showing Form:** Includes date and time picker.
* **Home Valuation Request Form:** Captures user property address, square footage, and condition for CMA (Comparative Market Analysis) requests.

## 3. Integrations
* **Google Maps:** Interactive maps on property detail pages and Contact Us page.
* **Social Media & Reviews:** Links to Facebook, Instagram, LinkedIn, and dynamic or static badges/links for Google, Zillow, and Redfin reviews.
* **SEO Optimization:** Dynamic meta tags, semantic HTML, schema markup for real estate, and optimized image loading.

## 4. Admin Dashboard
* **Property CRUD Interface:** Form-based UI to manually upload images, set prices, write descriptions, and toggle listing statuses.
* **Scraping Status Widget:** Displays the last sync time and success/failure status of the Zillow/Redfin scraping API.

## 5. Automated Data Pipeline
* **Zillow & Redfin Scraper API:** Custom-built API that utilizes a residential proxy network to bypass bot-detection, extracting the agent's specific sold and unsold properties.
